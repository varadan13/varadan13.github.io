TIL: Tagged Template Literals in JavaScript

Most JavaScript developers know template literals as a cleaner way to build strings:

const name = "Mike";
console.log(`Hello ${name}`);

Output:

Hello Mike
But what if you could intercept that process and decide what to return yourself?

That's what tagged templates do.

Instead of JavaScript immediately assembling the string, it hands the pieces to your function and lets your code decide what to return.

You can escape HTML, validate values, build SQL helpers, create DSLs, or even return objects instead of strings.

How it works

To tag a template literal, place a function name directly before the backtick:

myTag`That ${person} is a ${age}.`

JavaScript splits the template into two parts and calls your function:

myTag(
  ["That ", " is a ", "."],
  "Mike",
  28
)

The first argument is an array of all the literal string segments. The rest are the interpolated values, spread as individual arguments.

There is always one more string segment than expression.
strings.length === values.length + 1

Example — Customizing the output

const person = "Mike";
const age = 28;

function myTag(strings, personExp, ageExp) {
  const str0 = strings[0]; // "That "
  const str1 = strings[1]; // " is a "
  const str2 = strings[2]; // "."

  const ageStr = ageExp < 100 ? "youngster" : "centenarian";

  return `${str0}${personExp}${str1}${ageStr}${str2}`;
}

const output = myTag`That ${person} is a ${age}.`;

console.log(output);

Output:

That Mike is a youngster.

The tag function received 28 as a raw number, applied its own logic, and substituted "youngster" in its place. The final string never contained the age at all.

Chaining tags — a function that returns itself

function recursive(strings, ...values) {
  console.log(strings, values);
  return recursive;
}

recursive`Hello``World`;
What gets logged?

This is conceptually equivalent to:

recursive(`Hello`)(`World`)

But because these are tagged templates, JavaScript passes structured arguments — not bare strings.

First call:

strings = ["Hello"]
values  = []

The function returns itself. JavaScript immediately applies it as a tag to the next template:

strings = ["World"]
values  = []

Final output:

["Hello"] []
["World"] []

Any function that returns a callable can be chained this way.

The shape of a tag function

tag`Hi ${x}!`

// becomes

tag(["Hi ", "!"], x)

The name of the tag function can be anything. The return value can be anything — a string, an object, another function.

Flashcards

What does a tagged template function receive first?

An array containing the literal string segments.

Where do ${...} expressions go?

Into the remaining parameters (...values).

What does this become?
tag`Hi ${x}!`
tag(["Hi ", "!"], x)
Why does this work?
recursive`Hello``World`

Because the first tagged call returns another function, which immediately becomes the tag for the next template.

What is always true about strings and values?
strings.length === values.length + 1
What is the output?
function t(s, a) {
  return s[0] + a;
}

t`Age: ${10}`
Age: 10
Why use tagged templates over regular template literals?

To intercept the template and customize parsing, formatting, escaping, or validation — or to return something other than a string entirely.
