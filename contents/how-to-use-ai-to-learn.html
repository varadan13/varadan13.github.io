How to Use AI to Learn?

AI has not made learning optional. If learning were truly optional in the post-ChatGPT era, the world would already have vibe-coded WhatsApps and Instagrams — but we don't.

Can AI tools help us learn: a new programming language, system design, optimizations, testing, design thinking? Absolutely — and here's how.

Let's take an example.

Imagine you are learning networking from Udemy which provides lecture transcripts for every video. Copy the transcript, paste it into Claude, and ask it to generate small modular tutorials as markdown files for a beginner.

A 15-minute Udemy video is now broken down into multiple markdown files, each readable in under 5 minutes. Why is this useful? Immediate dopamine hit. When you read one markdown file and go "uh, I understand what it says!" — you are motivated to learn further and comprehend more if you engage with each of these files by creating examples or analogies or working code from them.

In other words, we are taking advantage of our instagramified brains.

Also don't skip the raw transcript or the lecture itself — AI can and does get things wrong.

Similarly, we can use AI to learn from codebases like React.

Let's look at Mithril.js, which is a frontend library that works similarly to React but is easier to read through.

Clone the codebase and use the following git commands to view it at an earlier stage of development: 

# list all commits from oldest to newest, one line each
git log --oneline --reverse

# select a commit and create a new branch at that point
git checkout -b review-branch selected-commit

Now you're looking at Mithril.js as it was in its early days — a much smaller, simpler codebase to learn from.

Open Claude and ask it to understand the codebase and then ask it to create small tutorials teaching you what the codebase does.

The pattern is simple: take something long and complex, hand it to AI, and ask it to break it down into bite-sized pieces you can actually absorb. Whether it's a Udemy lecture or an open-source codebase, AI doesn't learn for you — it makes the path to learning shorter. You still have to walk it.
