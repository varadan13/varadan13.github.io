How to Store an Entire Novel in a URL?

Let's say you want to store the data of an entire novel like Shakespeare's As You Like It in the URL. How do you do it?

We are going to use a simple HTML file and some JavaScript to do it.

The HTML file should allow us to display the novel.

Here is the HTML code that will do just that:

<article contenteditable="plaintext-only" spellcheck></article>

The code above will allow us to paste the entire novel into a text field-like UI.

Now let's write the JavaScript.

const article = document.querySelector("article");
const content = article.textContent;

The code above will grab the text content present within article.

async function compress(string) {
  const byteArray = new TextEncoder().encode(string);
  const stream = new CompressionStream("deflate-raw");
  const writer = stream.writable.getWriter();
  writer.write(byteArray);
  writer.close();
  const buffer = await new Response(stream.readable).arrayBuffer();
  return new Uint8Array(buffer).toBase64({ alphabet: "base64url" });
}

The code above is complicated, but the gist is that it takes the content string, compresses it to save space, encodes it into a base64 string, and ensures the output string can be used in a URL. 

async function save() {
  const content = article.textContent;
  const hash = "#" + (await compress(content));
  history.replaceState({}, "", hash);
}

The code above puts the pieces together â€” it grabs the text content, compresses it, and sets it as the hash of the URL. 

article.addEventListener("input", save);
article.addEventListener("blur", save);

The code above allows us to run the save function when we paste the text content of our favorite novel.

The code is not complete â€” when we reload, we are not reading the data embedded in the URL and feeding it into article, so nothing will be shown in the UI. 

const hash = location.hash;

In the code above, we are grabbing data from the hash of the URL.

async function decompress(b64) {
  const byteArray = Uint8Array.fromBase64(b64, { alphabet: "base64url" });
  const stream = new DecompressionStream("deflate-raw");
  const writer = stream.writable.getWriter();
  writer.write(byteArray);
  writer.close();
  const buffer = await new Response(stream.readable).arrayBuffer();
  return new TextDecoder().decode(buffer);
}

The code above does the inverse of the compress function.

async function set() {
  const hash = location.hash;
  const content = await decompress(hash.slice(1)); // See the save function to understand why this slice is needed
  article.textContent = content;
}

The code above does the following: it grabs the hash, decompresses it, and feeds it into the article element.

Still, we need a way to run the set function only when the document loads.

addEventListener("DOMContentLoaded", set);

The code above will now call the set function when the document loads.
