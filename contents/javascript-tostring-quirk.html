Why Does {}.toString Break in JavaScript?

In JavaScript, if we run

{}.toString
What do you think happens?

JavaScript throws the following error:

Uncaught SyntaxError: Unexpected token '.'
But why?

When JavaScript sees {}.toString, it makes an assumption that {} represents a block.

So in JavaScript's eyes {}.toString becomes:

{



}.toString;

This means that when JavaScript sees {}.toString, it thinks the {} is an empty code block. Then it sees .toString sitting alone after the block, which doesn't make sense — so it throws an error.

But why doesn't const toString = {}.toString; throw a SyntaxError?

Because now JavaScript can clearly see that {} is an object, and we are grabbing the toString property from it. No confusion, no error!
