TIL: How null and undefined are handled by Array.join()

[1, 2, 3].join(", ")

The code above will give the following output:

'1, 2, 3'

When any of the array elements are either null or undefined, join converts them to an empty string and applies the given separator. For example: 

[1, null, undefined, 2].join(", ")

The code above will give the following output:

'1, , , 2'
