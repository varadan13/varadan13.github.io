Was there anything analogous to vibe coding before ChatGPT, when Stack Overflow was used? Yes, there was. We could always “vibe build” software ever since the advent of the internet. Anyone could go online and figure out how to build a piece of software. The only difference now is that there is far less effort involved in the figuring-out phase and even up to the demo stage. So, how did we vibe code during the stack overflow era? Developers would go to Stack Overflow or blogs, try to figure out how to fix their issues, copy-paste code, and check whether the problem was solved. If it worked, they’d call it a day—everything ran, all features seemed fine. In many ways, this was what “vibe coding” looked like back then. What happened to softwares written like this?
